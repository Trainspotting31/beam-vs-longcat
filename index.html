LongCat-2.5 优势

适用场景

选 Beam 1.0

需要 SWE-bench 级别代码修复、长上下文分析、agentic coding 任务；预算允许 $0.40/M input。

选 LongCat-2.5

需要多模态（图像）、快速响应、低成本；任务较简单，不追求 SOTA 编程能力。

总结

Beam 1.0 在 编程基准（SWE-bench 80.9、Terminal-Bench 80.1）和 上下文长度（1M）上更强，适合 hardcore coding/agentic 任务。LongCat-2.5 在 速度（39.5 tps）、成本和 多模态上占优，适合快速/便宜/图像任务。AA 没给 LongCat 评分，直接对比有限；Beam 的 AA Coding Agent Index 仅 28，不算顶尖。
